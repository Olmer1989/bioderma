# BIODERMA × Фармленд — промо-сайт акции

Сайт акции «Покупайте BIODERMA — выигрывайте призы!»: покупки с 9 ноября по 6 декабря 2026,
выдача призов до 20 декабря 2026. Две страницы:

- `index.html` — лендинг: механика, призы, победители, вопросы и форма обратной связи, окна входа и регистрации;
- `lk.html` — личный кабинет: профиль, чеки, призы, окна загрузки чека и призов.

Чистые HTML + SASS + JavaScript (ES-модули), без фреймворков. Адаптив от 320 px до десктопа 1440 px.
Вёрстка готова целиком; серверной части нет — все места, куда её подключать, помечены `TODO` (список ниже).

## Запуск

Страницы открываются только через локальный сервер: JavaScript подключён как ES-модуль,
а по `file://` браузер модули не грузит. Подойдёт любой сервер из корня проекта, например:

```
npx serve .
```

## Сборка стилей

`css/main.css` уже собран и лежит в репозитории — сайт работает без сборки. Править стили нужно
в `sass/`, затем пересобрать:

```
npm install
npm run build:css     # один раз
npm run watch:css     # пересборка при каждом сохранении .sass
```

Нужен Node.js 20.19 или новее. Сборка: Dart Sass → Autoprefixer (браузеры `defaults`).
`css/main.css` руками не редактировать.

## Структура

```
├─ index.html, lk.html
├─ css/
│  ├─ main.css                 ← собирается из sass/
│  └─ vendor/dropzone.min.css  ← стили библиотеки загрузки файла
├─ sass/
│  ├─ main.sass                ← точка входа, только @use; порядок подключения важен
│  ├─ base/                    ← _variables (цвета, размеры, точки перелома), _mixins, _fonts, _reset, _global
│  ├─ layout/                  ← _header, _footer
│  ├─ components/              ← _button, _section-title, _promo-card, _accordion, _form-field, _status, _data-table
│  ├─ sections/                ← секции главной сверху вниз: _hero, _steps, _prizes, _main-prize, _winners, _help
│  ├─ pages/                   ← _lk (личный кабинет)
│  └─ promo-kit/               ← окна, формы, вкладки, загрузка файла (шаблон President) + _theme.sass
├─ js/
│  ├─ main.js                  ← точка входа: импорт и запуск модулей
│  ├─ modules/                 ← по одной задаче в файле (меню, вкладки и слайдер недель, видео,
│  │                              форма «Помощь», победители, загрузка чека, копирование промокода)
│  ├─ promo-kit/               ← popup.js, forms.js, tabs.js (шаблон President)
│  └─ vendor/dropzone.min.js   ← Dropzone 5.7
├─ fonts/                      ← Gotham Light / Book / Bold, woff2
├─ images/                     ← фото, видео (mp4 + постер), логотипы, иконки
└─ scripts/build-css.js        ← сборка стилей
```

В каждой папке `sass/*/` есть `_index.sass`, который подключает все её файлы: новый файл добавляется
одной строкой туда, `main.sass` трогать не нужно.

**Точки перелома** (`sass/base/_variables.sass`, desktop-first, `@include media(имя)` внутри блока):
`laptop` < 1280 (меню в бургер), `tablet` < 1024, `tablet-sm` < 768 (телефон), `mobile-sm` < 375.

## Окна и сценарии

Окно открывается кнопкой с `data-popup-open="id"` или из JS: `window.popup.open('id')`,
закрывается кнопкой с `data-popup-close`. Сейчас встроенные `onsubmit`-функции в HTML только
листают окна — в них подключается отправка на сервер.

**Главная (`index.html`)**

```
«Загрузить чек» / «Личный кабинет» ─► login
  ├─ вкладка «Вход»:        login-phone (телефон) ─► login-code (код из звонка) ─► lk.html
  └─ вкладка «Регистрация»: register-form ─► register-code (код из звонка) ─► lk.html
Форма «Помощь» ─► feedback-success
```

Шаги внутри вкладки переключает `switchAuthStep(fromId, toId)` (скрипт в начале окна `login`).

**Личный кабинет (`lk.html`)**

```
«Загрузить чек» ─► cheque (выбор способа)
   ├─ «С помощью камеры»     ─► cheque-camera ─┬─► cheque-in-self
   │                                           └─► cheque-info
   ├─ «Загрузить фотографию» ─► cheque-info (памятка) ─► cheque-load (Dropzone) ─► cheque-success
   └─ «Ввести вручную»       ─► cheque-in-self (ФН, ФД, ФП, дата, время, сумма) ─► cheque-success
Карточки «Промокод 2 000 ₽» / «4 000 ₽» ─► prize-promocode / prize-promocode-4000
prize-delivery ─► prize-delivery-success — анкета доставки подарочного набора (кнопки открытия пока нет)
```

**Блок «Победители»** — два состояния по атрибуту `data-published` у `#winners`:
`"false"` — заглушка до розыгрышей, `"true"` — таблица и поиск по номеру телефона.
В строке таблицы `data-phone` — открытые цифры номера; поиск срезает код страны (`+7`, `8`).

## Шаблон President (окна, формы, вкладки)

Окна, формы, вкладки и загрузка файла — шаблон
[RuslanMirasov/president-cheese](https://github.com/RuslanMirasov/president-cheese), коммит `ef91c10`:
`sass/promo-kit/_popup.scss`, `_forms.scss`, `_tabs.scss`, `_dropzone.scss`, `js/promo-kit/*`, `images/promo-kit/*`.
Оформление под сайт — в `sass/promo-kit/_theme.sass`, через переменные шаблона; файлы шаблона
можно обновлять копированием.

Изменения в самом шаблоне:
- `popup.js`: окна открываются по `click` (работает клавиатура), фокус переходит в окно и возвращается
  на кнопку после закрытия, страница под окном становится `inert`;
- `forms.js`: исправлено `innerHtml` → `innerHTML`, нет падения на поле без `<label>`, проверяются только
  формы с `class="form"`.

Шаблон стилизует по id — на страницах их не использовать для другого:
`faq`, `login`, `cheque`, `cheque-load`, `callback`, `callback-success`, `game-*`.

## Соглашения

- **БЭМ:** `блок__элемент--модификатор`, один блок — один файл `.sass`.
- **Цвета и размеры — из `sass/base/_variables.sass`.** Новое значение — сначала переменная.
- **JS** находит элементы по `data-*`, стили — по классам; модуль экспортирует одну `init…()`
  и сразу выходит, если нужного элемента на странице нет.
- **Картинки:** у каждого `<img>` есть `width` и `height`, ниже первого экрана — `loading="lazy"`.
  Анимации — MP4 с постером, видео в карточках грузятся при появлении на экране.
- **Новая версия картинки — новое имя файла.** На хостинге картинкам ставится долгий кэш,
  иначе посетители увидят старую. У шрифтов и логотипа подвала для этого стоит `?v=2`.
- **Доступность:** один `h1`, у секций `aria-labelledby`, у полей `<label>` (в окнах скрыт от глаз,
  подсказка — внутри поля), декоративные картинки с `alt=""`, видео — `aria-hidden`.
- **Форматирование** — Prettier (`.prettierrc`), отступы и переводы строк — `.editorconfig` (LF).
